# 九宮格 T9 小鍵盤拼音輸入工具

在 Windows 上用**數字小鍵盤**打九宮格拼音，再把拼音交給電腦上已有的中文輸入法
（微軟拼音、搜狗等）去組字。工具本身不建詞庫、不做漢字候選，只補上「九宮格」這一層。

```
小鍵盤 2 4  →  面板：1 ci   2 ai   3 bi
數字行 3    →  高亮 ci
Enter       →  送出 ci，輸入法跳出漢字候選
```

---

## 1. 功能

- 小鍵盤 `2–9` 輸入九宮格數字，即時產生合法拼音候選（含多音節切分，例如 `64426` → `nihao`）。
- 只輸入**單一數字**時，直接列出該鍵的全部字母（`2` → `a b c`、`7` → `p q r s`），即使不是合法音節也可選。
- 主鍵盤數字行 `1–9` 或**滑鼠點擊**選候選，`Enter` 送出。
- `0` 前綴通道：逐位選字母，可拼出任意字母串（簡拼），交給輸入法解釋。
- 懸浮面板**不搶焦點**：點它、拖它都不會把前景視窗切走。
- 面板四邊／四角可自由拖曳縮放（寬高各自獨立），字號另可單獨調整。
- 面板可收合成一顆小膠囊：按標題列 `—` 或 `Ctrl+Alt+M`；點膠囊還原，下次開始輸入時也會自動展開。
- 全域熱鍵：`Ctrl+Alt+N` 暫停／恢復攔截，`Ctrl+Alt+Q` 退出，`Ctrl+Alt+=` / `Ctrl+Alt+-` 調字號。
- 單一實例、記住面板位置、可打包成免安裝 EXE。

## 2. 系統需求

- Windows 10 / 11（x64）
- 原始碼執行：Python 3.10 以上（只用標準函式庫，含 tkinter）
- EXE：免安裝 Python

## 3. 執行

```powershell
# 從專案根目錄
python -m numpad_t9

# 或雙擊 / pythonw（不開主控台）
pythonw run.pyw
```

打包後的 EXE 直接雙擊 `T9NumPad.exe`。

## 4. 操作

### 4.1 標準模式

| 按鍵 | 作用 | 攔截時機 |
|---|---|---|
| 小鍵盤 `2–9` | 追加九宮格數字 | 工具啟用時一律攔截 |
| 數字行 `1–9` | 選第 N 個候選（只移動高亮） | **僅面板有候選時** |
| 滑鼠點候選 | 標準模式直接送出；`0` 前綴模式填入該位字母 | 面板顯示時 |
| `Enter` | 送出目前高亮的拼音 | 有緩衝時 |
| `Backspace` | 刪掉最後一位數字 | 有緩衝時 |
| `Esc` | 取消整串輸入 | 有緩衝時 |
| 小鍵盤 `*` / `/` | 上一頁 / 下一頁候選 | 有候選時 |
| 小鍵盤 `0` | 進入 `0` 前綴通道 | 緩衝為空時 |
| `Ctrl+Alt+=` / `Ctrl+Alt+-` | 字號放大／縮小 | 隨時 |
| `Ctrl+Alt+0` | 字號還原成 1.15× | 隨時 |
| `Ctrl+Alt+M` | 收合／展開面板 | 隨時 |
| `Ctrl+Alt+N` | 暫停／恢復攔截 | 隨時 |
| `Ctrl+Alt+Q` | 退出 | 隨時 |

- 候選依「音節數少者優先、常用音節優先」排序；常見簡拼片語（`nihao`、`xiexie`…）會加分。
- **單一數字是特例**：不做拼音過濾，直接列出該鍵全部字母（`2` → `a b c`、`9` → `w x y z`），
  由使用者自己選；選完仍要按 `Enter` 才送出。多位數字仍走完整拼音解析。
- 只有一個候選時，仍然要按 `Enter`，工具**絕不自動送出**。
- 數字行帶 `Shift` / `Ctrl` / `Alt` 的組合（`!@#$`、`Ctrl+1`）一律放行。
- **送出瞬間就解除數字行攔截**，組字框一出現，`1–9` 就已經是輸入法在用了。

### 4.2 `0` 前綴（簡拼通道）

```
0            → 進入 0 前綴
6            → 面板：1 m  2 n  3 o
數字行 2     → 選 n
9            → 面板：1 w  2 x  3 y  4 z
數字行 1     → 選 w
Enter        → 送出 nw → 輸入法給「魔王 / 末尾 / 摸我」
```

- 這個通道**不套拼音規則**：每一位的字母都由使用者用數字行指定，因此 `cz`、`mw`、`ng` 都能送。
- 數字可以先連打再逐位選，也可以邊打邊選。
- `Backspace` 退掉最後一位（連數字帶字母）；`Esc` 取消；尚未輸入任何數字時按 `0` 離開。

### 4.3 小鍵盤被「佔用」的範圍

工具啟用時，小鍵盤 `0–9` 都歸工具（`1` 保留），因此這段時間不能用小鍵盤打數字。
需要打數字時按 `Ctrl+Alt+N` 暫停，用完再按一次恢復。面板上的「暫停／啟用」按鈕同效。

## 5. 與輸入法整合

- 送出拼音用的是**模擬字母按鍵**（`SendInput` 的 VK 事件），不是 Unicode 直接上屏，
  所以輸入法會照常進入組字、彈出自己的漢字候選。
- 輸入法必須在**中文模式**。面板右上角在偵測得到時會顯示 `中` / `英`；
  查不到（部分 TSF 輸入法或權限不足）就不顯示，不會佔一個看不懂的符號。
- 目標程式若以管理員權限執行，本工具也要以管理員執行，否則 Windows 會擋下注入（UIPI）。
- 候選、詞庫、聯想、簡拼全部由輸入法負責，本工具不建立任何漢字資料。

## 6. 設定

`%APPDATA%\T9NumPad\config.json`

```json
{ "x": 1200, "y": 800, "w": 705, "h": 321, "font_scale": 1.15, "enabled": true }
```

面板可以拖曳標題列移動，拖曳四邊／四角改變寬高（非等比）；字號用
`Ctrl+Alt+=` / `Ctrl+Alt+-` 調整（`Ctrl+Alt+0` 還原 1.15×）。
字號與視窗大小互相獨立：字號變大時，視窗若太小會自動長到能放下的最小尺寸。
位置、尺寸、字號都會在關閉時記住，`enabled` 記錄上次的攔截狀態。

## 7. 建置 EXE

```powershell
powershell -ExecutionPolicy Bypass -File build_exe.ps1
```

會安裝 PyInstaller、產生 `assets\t9.ico`，輸出 `dist\T9NumPad.exe`（單檔、無主控台）。

## 8. 專案結構

```
numpad_t9/
├─ t9_pinyin.py      數字→拼音候選、0 前綴、輸入狀態機（純邏輯，可單元測試）
├─ win32_api.py      SendInput、鉤子所需 API、DPI、單一實例、IME 狀態
├─ keyboard_hook.py  WH_KEYBOARD_LL 鉤子（安裝與訊息迴圈在同一個執行緒）
├─ overlay.py        tkinter Canvas 面板（WS_EX_NOACTIVATE，不搶焦點）
├─ config.py         設定檔
└─ app.py            入口：組裝鉤子、引擎、面板
tests/test_engine.py 29 個單元測試（不需要 Windows API）
tools/make_icon.py   純標準函式庫產生 .ico
run.pyw              PyInstaller 進入點
build_exe.ps1        打包腳本
```

## 9. 疑難排解

| 現象 | 可能原因與處理 |
|---|---|
| 按小鍵盤完全沒反應 | 鉤子被安全軟體或權限擋住；改用「以系統管理員身分執行」。若仍無效，關閉其他鍵盤攔截工具（AutoHotkey 等）再試。 |
| 面板有反應，但輸入法沒組字 | 輸入法在英文模式；或目標視窗以更高權限執行。看面板右上角 `中/英`。 |
| 送出後數字行選不到漢字 | 正常情況下面板會清空、攔截已解除；若仍不行，確認焦點沒有被其他視窗搶走。 |
| 小鍵盤打不出數字 | 工具正在接管小鍵盤；按 `Ctrl+Alt+N` 暫停。 |
| 筆電沒有獨立小鍵盤 | 需要外接數字鍵盤（或改用有 NumPad 的鍵盤）。 |

## 10. 已知限制

- 只支援 Windows。
- 工具啟用期間小鍵盤 `0–9` 被接管（這是設計，不是 bug）。
- AZERTY 等「數字需要按 Shift」的鍵盤配置，數字行選字不適用（目前以 US 佈局為主）。
- 鉤子無法攔截以更高權限執行的程式所收到的按鍵。
- 沒有小鍵盤的筆電無法使用。

## 11. 設計備註

- 候選只做拼音層：合法音節表 + 多音節切分 + 排序；`n / ng / m / hm / hng` 等罕用音節
  保留在表中，只靠排序壓到後面，不靠刪除降噪。
- `0` 前綴不套拼音規則，逐位由使用者指定字母，所以能送 `ng` 這種「那個／哪個／拿個」的簡拼。
- 數字行攔截範圍嚴格限定在「有候選待確認」期間，其餘時間完全放行。
